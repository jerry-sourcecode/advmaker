# 时间系统

ADVMaker 内置了轻量级的游戏内时间系统，时间通过**状态栏自动展示**，无需额外配置。

## 配置

在 `game.config.ts` 中设置起始时间：

```typescript
export default Adv.defineConfig({
    // ... 其他配置
    time: {
        start: '1925-09-12 08:00', // 必填，格式 YYYY-MM-DD HH:mm
        showDate: false, // 可选，是否在状态栏显示日期（默认 false）
    },
});
```

- `start`：游戏开始时间，精确到分钟
- `showDate`：为 `true` 时状态栏显示 `MM-DD HH:MM`，为 `false` 时仅显示 `HH:MM`

若你想要禁用，你可以不填写 time 配置项，这样会自动全局隐藏。

## 状态栏展示

时间会**自动注册**为一个名为 `__time__` 的 string 型状态，`isDisplay: 'text'`，显示在顶部状态栏的最右侧。你无需手动添加。

## 推进时间

通过 `Adv.time.advance(minutes)` 推进游戏内时间：

```typescript
// 推进 30 分钟
Adv.time.advance(30);

// 推进 2 小时
Adv.time.advance(120);

// 在故事中使用
<ARun :run="() => Adv.time.advance(30)" />
```

时间推进后，状态栏的时间会自动更新。

## 读取时间

| API             | 返回值示例                   | 说明                                 |
| --------------- | ---------------------------- | ------------------------------------ |
| `Adv.time.str`  | `"08:00"` 或 `"09-12 08:00"` | 状态栏显示格式，根据 `showDate` 配置 |
| `Adv.time.full` | `"1925-09-12 08:00 星期六"`  | 完整日期时间，含星期                 |

## 故事菜单

在菜单中打开「故事」页面时，选项卡上方会显示完整的日期时间和星期。
