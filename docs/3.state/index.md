# 第三章 状态记录

一个令人沉浸的冒险故事，除了生动的场景和对话，还需要一个鲜活的“主角”。你的玩家会成长、会受伤、会拾取道具、会在商店里精打细算，也会想要在艰难抉择前存个档。

在这个章节，你将学习 ADVMaker 中用于记录玩家状态的六大模块：**属性**、**背包**、**商店**、**故事**、**线索**以及**时间**模块。 掌握了这些，你将能够让游戏记住玩家的每一点力量、每一件道具、每一次交易、每一个重要的历史节点、每一条收集到的线索信息，以及每一秒流逝的游戏内时间。让我们开始吧！
