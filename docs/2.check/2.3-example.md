# 综合示例

假设我们希望在对话中让玩家尝试撬锁，根据其“敏捷”属性进行检定：

```typescript
Adv.appendDialog('lockpick-dialog', {
    script: ['你尝试用发卡撬开这扇门...'],
    check: {
        dice: 'd20', // 投一个20面骰
        target: () => 10, // 目标为玩家的敏捷值，此处为 10
        modifier: [
            { name: '撬锁工具加成', value: () => 2 },
            { name: '疲劳惩罚', value: () => -1 },
        ],
        success: 'door-open-dialog', // 成功则进入开门对话
        fail: 'door-stuck-dialog', // 失败则进入卡住对话
        onSuccess: () => console.log('门开了！'),
        onFail: () => console.log('门卡住了...'),
    },
});
```

在这个例子中，程序会先掷一个 `d20`，假设结果为 `14`，然后加上修正 `2 - 1 = 1`，最终点数 `15`。如果此时玩家的敏捷值等于或低于 `15`，则检定成功；否则失败。

关于动态储存玩家属性，请参见**第三章 状态记录**。

如果你想手动触发一次检定：

```typescript
const result = await Adv.check(checker);
// result: { res: boolean, nat: number, dirty: number }
//   res:   检定是否成功
//   nat:   原始掷骰值（natural roll）
//   dirty: 最终检定值（原始值 + 修正）
```

`checker` 是一个检定对象（`ADVUserCheck`），描述这一次检定。

`Adv.check()` 返回一个对象，包含三个字段：

| 字段    | 类型      | 说明                                   |
| ------- | --------- | -------------------------------------- |
| `res`   | `boolean` | 检定是否成功                           |
| `nat`   | `number`  | 原始掷骰值，修正前的结果               |
| `dirty` | `number`  | 最终检定值，原始值加上所有修正后的结果 |

# 检定的方法

本项目支持配置检定使用何种方法。

在全局设置（`game.config.ts`）中设置字段 `judgmentMode`，其有以下取值：

- `d20`：类似 D&D 的检定方法。这种情况下骰子的默认是 `d20`（默认）
- `percent`：类似 CoC 检定方法。这种情况下骰子的默认是 `d100`

## CoC 多等级检定示例

在 `percent` 模式下，你可以利用 `.hard` 和 `.extreme` 属性快速实现 CoC 风格的多等级检定：

```xml
<ACheck :target="() => Adv.status.SpotHidden.hard" target-desc="侦查检定（困难）"
    :dice="'d100'">
    <template #success="{ nat, dirty }">
        <ALine>你发现了隐藏在书柜后的暗格！(掷骰 {{ dirty }})</ALine>
    </template>
    <template #fail="{ nat, dirty }">
        <ALine>你仔细查看了房间，但没有任何发现。(掷骰 {{ dirty }})</ALine>
    </template>
</ACheck>
```

或者写一个更复杂的例子，在同一个检定中处理多个难度等级：

```xml
<ACheck :target="() => Adv.status.LibraryUse.extreme" target-desc="图书馆使用（极难）"
    :dice="'d100'">
    <template #success="{ nat, dirty }">
        <ALine>你迅速找到了那本稀有典籍！(极难成功，掷骰 {{ dirty }})</ALine>
    </template>
    <template #fail="{ nat, dirty }">
        <AIf :condition="() => dirty <= Adv.status.LibraryUse.hard">
            <ALine>虽然没有找到那本典籍，但你发现了一些有用的线索。(困难成功，掷骰 {{ dirty }})</ALine>
        </AIf>
        <AElse>
            <ALine>你在书架间徘徊许久，一无所获。</ALine>
        </AElse>
    </template>
</ACheck>
```

> **提示**：在 `percent` 模式下，`ACheck` 判定成功的规则是 **掷骰结果 ≤ 目标值**。因此 `target` 设为极难阈值时，困难成功的判定需要在 `#fail` 中手动处理。
