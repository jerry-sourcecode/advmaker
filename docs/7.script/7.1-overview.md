# 功能一览

Adv Script 是一种语法类似于 C++ 的领域专用语言，其文件后缀为 `.adv`，引擎中内置了一个翻译系统，能够将 `.adv` 文件转换为第五章所提及的 `.vue` 文件。

需要开始编写你需要运行下面的命令：

```bash
npm run adv:watch
```

这段命令会启动翻译系统，会在保存时自动将 `.adv` 文件转换为 `.vue` 文件。

如果你决定使用 Adv Script 来编写故事，你不需要编写 `App.vue` 和 `game.config.ts`。你需要将所有的 `.adv` 文件放置在 `src/script` 之中。

翻译系统会读取 `src/script` 中的每一个文件，并按照原来的文件结构将翻译后的文件放置在 `src/dist` 之中。并且自动生成 `App.vue` 和 `game.config.ts`。

对于一个 `adv` 文件，其基本架构如下，这些元素可以按照任意顺序排列：

```
code*                 // 零个或多个全局代码块
game { ... }          // 全局配置（最多每个文件只能有一个）
scene*                // 零个或多个场景
dialog*               // 零个或多个顶层对话
```
