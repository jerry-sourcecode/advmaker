# 第六章 错误处理

在开发文字冒险游戏时，你可能会遇到各种运行时错误——比如引用了一个不存在的场景、给字符串状态赋了数字值、或者定义了重复的 ID。这些错误如果不及时暴露，轻则导致剧情走偏，重则让整个游戏白屏崩溃。

ADVMaker 内置了一套**运行时错误（RuntimeError）**体系，它会在发生逻辑错误时立即抛出异常，帮助你在开发阶段快速定位问题。

在这个章节中，你将了解所有错误码的含义、触发场景，以及如何利用这些错误信息高效调试你的游戏。
